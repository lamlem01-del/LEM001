
## ១២.៦ ផែនទីបង្ហាញផ្លូវ សម្រាប់ការអនុវត្ត (២០២៦–២០៣៥)

ក្របខណ្ឌសន្តិភាពពហុស្រទាប់ (ផ្នែក ១២.៣) និងអនុសាសន៍ (ផ្នែក ១២.៤) នឹងគ្មានតម្លៃ ប្រសិនបើគ្មានផែនការអនុវត្ត ជាក់ស្តែង។ ផ្នែកនេះ ស្នើផែនទីបង្ហាញផ្លូវ (roadmap) ជាបីដំណាក់កាល ជាមួយសកម្មភាព តួអង្គទទួលខុសត្រូវ និងសូចនាករ នៃវឌ្ឍនភាព។ ផែនទីនេះ ត្រូវបានរចនា ឱ្យមានភាពបត់បែន — សកម្មភាព ក្នុងដំណាក់កាលនីមួយៗ អាចចាប់ផ្តើម ស្របគ្នា ហើយវឌ្ឍនភាព ក្នុងស្រទាប់មួយ មិនគួររង់ចាំ វឌ្ឍនភាព ក្នុងស្រទាប់ផ្សេងទៀតឡើយ។

### ១២.៦.១ ដំណាក់កាលទី១៖ ស្ថិរភាព (២០២៦–២០២៧)

**គោលដៅ៖** ការពារការវិលត្រឡប់ នៃអរិភាព និងបង្កើតមូលដ្ឋាន សម្រាប់ទំនុកចិត្ត។

| សកម្មភាព | តួអង្គទទួលខុសត្រូវ | សូចនាករ |
|---|---|---|
| ធ្វើឱ្យ AOT ក្លាយជាយន្តការអចិន្ត្រៃយ៍ ជាមួយអាណត្តិ និងថវិកាច្បាស់លាស់ | អាស៊ាន ភាគីទាំងពីរ | AOT ដាក់ពង្រាយ ជាប្រចាំ ≥ ៥០ នាក់ |
| បង្កើតក្រុមស៊ើបអង្កេតបច្ចេកទេសរួម (មីន ការបាញ់ប្រហារ) | GBC អាស៊ាន (ARMAC) | ឧប្បត្តិហេតុ ត្រូវបានស៊ើបអង្កេត ក្នុង ៤៨ ម៉ោង |
| កំណត់តំបន់គ្មានយោធា នៅជុំវិញប្រាសាទ និងចំណុចប៉ះទង្គិច | GBC/RBC | ផែនទី តំបន់គ្មានយោធា ត្រូវបានអនុម័ត |
| ដកអាវុធធុនធ្ងន់ ចេញពីតំបន់ព្រំដែន (ចម្ងាយកំណត់) | កងទ័ពទាំងពីរ | របាយការណ៍ផ្ទៀងផ្ទាត់ ពី AOT |
| បោសសម្អាតគ្រាប់មិនទាន់ផ្ទុះ ពីសង្គ្រាម ២០២៥ នៅតំបន់ស៊ីវិល | CMAC/CMAA TMAC ដៃគូ | % តំបន់ស៊ីវិល ដែលបានបោសសម្អាត |
| ស្តារការធ្វើដំណើរ និងពាណិជ្ជកម្ម តាមច្រកព្រំដែនសំខាន់ៗ | ក្រសួងពាណិជ្ជកម្ម មហាផ្ទៃ | ចំនួនច្រក ដែលបើកឡើងវិញ |
| បង្កើតខ្សែទូរស័ព្ទក្រហម ជាស្ថាប័ន គ្រប់កម្រិត | ក្រសួងការពារជាតិ | ការសាកល្បង ប្រចាំខែ |
| ការគាំទ្រផ្លូវចិត្ត និងការស្តារ សម្រាប់ប្រជាជនរងគ្រោះ | ក្រសួងសុខាភិបាល សង្គមកិច្ច អង្គការមនុស្សធម៌ | ចំនួនប្រជាជន ដែលទទួលការគាំទ្រ |
| ការពារ និងស្តារសិទ្ធិ របស់ពលករចំណាកស្រុក | ក្រសួងការងារ ទាំងពីរ | MOU ការងារ ធ្វើបច្ចុប្បន្នភាព |
| បង្កើត "ក្រុមមិត្តភក្តិ នៃសន្តិភាព" | អាស៊ាន មហាអំណាច | ក្រុម ត្រូវបានបង្កើត និងប្រជុំ ជាប្រចាំ |

### ១២.៦.២ ដំណាក់កាលទី២៖ ការដោះស្រាយ (២០២៧–២០៣០)

**គោលដៅ៖** ដោះស្រាយបញ្ហាព្រំដែន ដែលអាចដោះស្រាយបាន និងបង្កើតយន្តការ សម្រាប់បញ្ហាដែលនៅសល់។

| សកម្មភាព | តួអង្គទទួលខុសត្រូវ | សូចនាករ |
|---|---|---|
| ពន្លឿនការងារ JBC នៅតំបន់គ្មានជម្លោះ ជាមួយបច្ចេកវិទ្យាទំនើប | JBC អ្នកជំនាញអន្តរជាតិ | គីឡូម៉ែត្រ នៃព្រំដែន ដែលបានបោះបង្គោល |
| ព្រមព្រៀង លើយន្តការដោះស្រាយវិវាទ ដែលមានកាតព្វកិច្ចចង សម្រាប់តំបន់ជម្លោះ | រដ្ឋាភិបាលទាំងពីរ | កិច្ចព្រមព្រៀង ត្រូវបានចុះហត្ថលេខា |
| ការស៊ើបអង្កេតឯករាជ្យ លើការរំលោភច្បាប់មនុស្សធម៌ ឆ្នាំ២០២៥ | ភាគីទាំងពីរ អ្នកជំនាញឯករាជ្យ | របាយការណ៍ ត្រូវបានចេញផ្សាយ |
| ចាប់ផ្តើមការសិក្សាលទ្ធភាព "ឧទ្យានសន្តិភាពដងរែក" | ក្រសួងវប្បធម៌ បរិស្ថាន យូណេស្កូ | របាយការណ៍សិក្សា ត្រូវបានអនុម័ត |
| បង្កើតគណៈកម្មការអ្នកប្រវត្តិសាស្ត្ររួម | សាកលវិទ្យាល័យ ក្រសួងអប់រំ | គណៈកម្មការ ប្រជុំ ជាប្រចាំ |
| បោសសម្អាតមីន នៅតំបន់ព្រំដែនអាទិភាព | CMAC TMAC ARMAC | ផ្ទៃ ដែលបានបោសសម្អាត |
| តំបន់សេដ្ឋកិច្ចព្រំដែន គម្រោងសាកល្បង | ក្រសួងសេដ្ឋកិច្ច វិស័យឯកជន | ការវិនិយោគ ការងារ ដែលបានបង្កើត |
| កម្មវិធីផ្លាស់ប្តូរយុវជន និងនិស្សិត | ក្រសួងអប់រំ សាកលវិទ្យាល័យ | ចំនួនអ្នកចូលរួម |
| កិច្ចសហប្រតិបត្តិការ ប្រឆាំងមជ្ឈមណ្ឌលបោកប្រាស់ | ប៉ូលិស ក្រសួងយុត្តិធម៌ | ករណី ដែលបានបង្ក្រាប រួមគ្នា |

### ១២.៦.៣ ដំណាក់កាលទី៣៖ ការបំប្លែង (២០៣០–២០៣៥)

**គោលដៅ៖** បំប្លែងព្រំដែន ពីតំបន់ជម្លោះ ទៅជាតំបន់សហប្រតិបត្តិការ។

| សកម្មភាព | តួអង្គទទួលខុសត្រូវ | សូចនាករ |
|---|---|---|
| អនុវត្តការសម្រេច នៃយន្តការដោះស្រាយវិវាទ | រដ្ឋាភិបាលទាំងពីរ | ព្រំដែន ត្រូវបានកំណត់ពេញលេញ |
| បង្កើត "ឧទ្យានសន្តិភាព និងបេតិកភណ្ឌដងរែក" | រដ្ឋាភិបាលទាំងពីរ យូណេស្កូ | ឧទ្យាន ដំណើរការ ការចូលទស្សនាពីសងខាង |
| ការដាក់ពាក្យ ចុះបញ្ជីបេតិកភណ្ឌពិភពលោក ឆ្លងដែន | ក្រសួងវប្បធម៌ ទាំងពីរ | ឯកសារ ត្រូវបានដាក់ជូន |
| បញ្ចូលខ្លឹមសារប្រវត្តិសាស្ត្ររួម ក្នុងសៀវភៅសិក្សា | ក្រសួងអប់រំ | សៀវភៅសិក្សា ត្រូវបានកែសម្រួល |
| ការអភិវឌ្ឍរួម នៅតំបន់ OCA | ក្រសួងរ៉ែ និងថាមពល | កិច្ចព្រមព្រៀង អភិវឌ្ឍន៍រួម |
| ការប្រារព្ធ "ថ្ងៃមិត្តភាពកម្ពុជា–ថៃ" ប្រចាំឆ្នាំ | រដ្ឋាភិបាល សង្គមស៊ីវិល | ព្រឹត្តិការណ៍ ប្រចាំឆ្នាំ |
| វិមានរំលឹក ជនរងគ្រោះ ទាំងសងខាង | រដ្ឋាភិបាល សហគមន៍ | វិមាន ត្រូវបានសាងសង់ |

### ១២.៦.៤ ការត្រួតពិនិត្យ និងវាយតម្លៃ

ដើម្បីធានាការអនុវត្ត ផែនទីបង្ហាញផ្លូវ គួរតែមានយន្តការត្រួតពិនិត្យ និងវាយតម្លៃ (M&E) ដែលរួមមាន៖ (ក) **របាយការណ៍ប្រចាំឆ្នាំ** ពីគណៈកម្មាធិការរួម ទៅកាន់មេដឹកនាំ នៃប្រទេសទាំងពីរ និងប្រធានអាស៊ាន (ខ) **ការវាយតម្លៃឯករាជ្យ** រៀងរាល់ ៣ ឆ្នាំ ដោយវិទ្យាស្ថានស្រាវជ្រាវ អព្យាក្រឹត (គ) **សូចនាករសន្តិភាព** ដែលរួមមាន ចំនួនឧប្បត្តិហេតុ ពាណិជ្ជកម្មឆ្លងដែន ការធ្វើដំណើរ ការស្ទង់មតិ អំពីការយល់ឃើញ របស់ប្រជាជន ចំពោះប្រទេសជិតខាង និង (ឃ) **ការចូលរួមពីសាធារណៈ** តាមរយៈវេទិកា សម្រាប់សហគមន៍ព្រំដែន ក្នុងការផ្តល់មតិយោបល់។

## ១២.៧ ឆ្លុះបញ្ចាំងចុងក្រោយ៖ តួនាទីរបស់អ្នកប្រាជ្ញ

និក្ខេបបទនេះ ត្រូវបានសរសេរ ក្នុងរយៈពេល ដែលជម្លោះ នៅតែកំពុងបន្ត។ ការសរសេរអំពីជម្លោះ ដែលកំពុងកើតឡើង ក្នុងនាមជាពលរដ្ឋ នៃភាគីមួយ គឺជាបញ្ហាប្រឈម ទាំងផ្នែកបញ្ញា និងផ្នែកសីលធម៌។ អ្នកស្រាវជ្រាវ ត្រូវតែរក្សាតុល្យភាព រវាងការប្តេជ្ញាចិត្ត ចំពោះការពិត និងភាពស្មោះត្រង់ ចំពោះប្រទេសជាតិ — តុល្យភាព ដែលមិនតែងតែងាយស្រួលនោះទេ។

ក្នុងបរិយាកាស នៃជាតិនិយម និងសង្គ្រាមព័ត៌មាន តួនាទីរបស់អ្នកប្រាជ្ញ មានសារៈសំខាន់ពិសេស។ អ្នកប្រាជ្ញ មិនត្រូវធ្វើជាអ្នកឃោសនា សម្រាប់ភាគីណាមួយ ឡើយ — ប៉ុន្តែក៏មិនត្រូវមើលរំលង ការឈឺចាប់ និងការអះអាងស្របច្បាប់ របស់ប្រជាជនខ្លួនដែរ។ តួនាទីរបស់អ្នកប្រាជ្ញ គឺ៖ (ក) ស្វែងរក និងបង្ហាញការពិត ដោយផ្អែកលើភស្តុតាង (ខ) បង្ហាញទស្សនៈ ជាច្រើន រួមទាំងទស្សនៈ របស់ភាគីម្ខាងទៀត ដោយយុត្តិធម៌ (គ) រិះគន់ ការប្រើប្រាស់ជម្លោះ ដោយអ្នកនយោបាយ ទាំងសងខាង (ឃ) ផ្តល់ដំណោះស្រាយ ដែលផ្អែកលើការវិភាគ និងមេរៀន ពីបទពិសោធន៍ ផ្សេងៗ និង (ង) កសាងស្ពាន ជាមួយអ្នកប្រាជ្ញ នៃភាគីម្ខាងទៀត។

អ្នកប្រាជ្ញ ថៃ ដូចជា លោកស្រី Puangthong Pawakapan លោក Charnvit Kasetsiri និងលោក Thongchai Winichakul ដែលបានរិះគន់ ការប្រើប្រាស់ជាតិនិយម ដោយអ្នកនយោបាយថៃ ដោយមិនខ្លាចការចោទប្រកាន់ ថា "ក្បត់ជាតិ" គឺជាគំរូ នៃភាពក្លាហានផ្នែកបញ្ញា។ អ្នកស្រាវជ្រាវ សង្ឃឹមថា និក្ខេបបទនេះ នឹងរួមចំណែក តាមវិធីស្រដៀងគ្នា ពីទស្សនៈកម្ពុជា — ការការពារសិទ្ធិស្របច្បាប់ របស់កម្ពុជា ដោយផ្អែកលើច្បាប់អន្តរជាតិ និងភស្តុតាង ខណៈពេលដែលរិះគន់ ដោយស្មោះត្រង់ នូវអ្វីដែលគួររិះគន់ និងបើកចំហ ចំពោះការសន្ទនា ជាមួយភាគីម្ខាងទៀត។

## សេចក្តីបញ្ចប់

ជួរភ្នំដងរែក ដែលបានឈរជាសាក្សី នៃការរីកចម្រើន និងការធ្លាក់ចុះ នៃអាណាចក្រ ការមកដល់ និងការចាកចេញ នៃអាណានិគម និងសង្គ្រាម និងសន្តិភាព អស់រយៈពេលរាប់សតវត្សរ៍ នៅតែឈរនៅទីនោះ។ ប្រាសាទព្រះវិហារ ដែលដូនតាខ្មែរ បានសាងសង់ ជាទីសក្ការៈ ដល់ព្រះឥសូរ នៅលើកំពូលភ្នំ ជាង ៩០០ ឆ្នាំមុន ត្រូវបានរចនាឡើង ជាស្ពានរវាងផែនដី និងស្ថានសួគ៌ — មិនមែនជាជញ្ជាំង រវាងប្រជាជនពីរនោះទេ។

ប្រជាជនកម្ពុជា និងថៃ ចែករំលែកច្រើនជាងអ្វីដែលបំបែកពួកគេ — សាសនាតែមួយ អក្សរសាស្ត្រ សិល្បៈ ពាក្យសម្តី ម្ហូបអាហារ និងប្រវត្តិសាស្ត្រ ដែលជាប់ទាក់ទងគ្នា ជាងមួយពាន់ឆ្នាំ។ ជម្លោះព្រំដែន មិនមែនជាវាសនា ដែលមិនអាចជៀសវាងបាននោះទេ — វាជាលទ្ធផល នៃជម្រើស ដែលមនុស្ស ធ្វើ។ ដូចដែលនិក្ខេបបទនេះ បានបង្ហាញ ជម្លោះកើនឡើង នៅពេលដែលឥស្សរជន ជ្រើសរើសប្រើប្រាស់វា ដើម្បីផលប្រយោជន៍នយោបាយ ហើយវាស្ងប់ស្ងាត់ នៅពេលដែលពួកគេ ជ្រើសរើសសហប្រតិបត្តិការ។

ការទទួលខុសត្រូវ សម្រាប់សន្តិភាព ស្ថិតនៅលើស្មារបស់មេដឹកនាំ ទាំងសងខាង — ប៉ុន្តែក៏ស្ថិតនៅលើស្មារបស់ប្រជាជនផងដែរ ដែលមានអំណាច ក្នុងការបដិសេធការស្អប់ខ្ពើម ទាមទារការដោះស្រាយ ដោយសន្តិវិធី និងកសាងស្ពាន ជំនួសឱ្យជញ្ជាំង។ សូមឱ្យការចងចាំ អំពីអ្នកដែលបានបាត់បង់ជីវិត ទាំងសងខាងព្រំដែន ក្លាយជាការដាស់តឿន ដែលមិនឈប់ឈរ អំពីតម្លៃនៃសង្គ្រាម និងភាពចាំបាច់ នៃសន្តិភាព។

ដូចដែលព្រះពុទ្ធ បានត្រាស់ក្នុងធម្មបទ៖ **"ពៀរ មិនដែលរម្ងាប់ដោយពៀរ ក្នុងលោកនេះឡើយ ពៀររម្ងាប់ដោយការមិនចងពៀរ នេះជាធម៌ដ៏ចាស់"** (ធម្មបទ គាថាទី៥)។
