# ឧបសម្ព័ន្ធ

| វិច្ឆិកា* | ឧប្បត្តិហេតុបាញ់ប្រហារ នៅភូមិព្រៃចាន់ ជនស៊ីវិលកម្ពុជាម្នាក់ ស្លាប់ |
| ~៧–៨ ធ្នូ* | អរិភាពផ្ទុះឡើងវិញ ថៃ វាយប្រហារតាមអាកាស |
| ពាក់កណ្តាលខែធ្នូ* | នាយករដ្ឋមន្ត្រីថៃ ប្រកាសរំលាយរដ្ឋសភា |
| ~២៧ ធ្នូ* | បទឈប់បាញ់ថ្មី តាមរយៈកិច្ចប្រជុំ GBC |
| ~៣១ ធ្នូ* | ទាហានកម្ពុជា ១៨ នាក់ ត្រូវបានដោះលែង |

## ឧបសម្ព័ន្ធ ខ៖ សេចក្តីសង្ខេបឯកសារច្បាប់សំខាន់ៗ

### ខ.១ អនុសញ្ញាបារាំង–សៀម ថ្ងៃទី១៣ ខែកុម្ភៈ ឆ្នាំ១៩០៤ (ដកស្រង់មាត្រាពាក់ព័ន្ធ)

**មាត្រា ១ (សេចក្តីសង្ខេប)៖** ព្រំដែនរវាងសៀម និងកម្ពុជា ចាប់ផ្តើមពីមាត់ព្រែកកំពង់ទ្រាច នៅច្រាំងខាងឆ្វេងនៃបឹងទន្លេសាប ធ្វើតាមព្រំប្រទល់រវាងខេត្តផ្សេងៗ ហើយបន្ទាប់មក ធ្វើតាមកំពូលភ្នំដងរែក "ដោយធ្វើតាមខ្សែបែងចែកទឹក រវាងអាងទន្លេញ៉ែន និងទន្លេមេគង្គ ម្ខាង និងទន្លេមូន ម្ខាងទៀត" រហូតដល់ទន្លេមេគង្គ។

**មាត្រា ៣ (សេចក្តីសង្ខេប)៖** ការកំណត់ព្រំដែន ដែលបានចែងក្នុងមាត្រា ១ ត្រូវអនុវត្ត ដោយគណៈកម្មការចម្រុះ ដែលមានមន្ត្រីតែងតាំង ដោយភាគីទាំងពីរ។

### ខ.២ សន្ធិសញ្ញាបារាំង–សៀម ថ្ងៃទី២៣ ខែមីនា ឆ្នាំ១៩០៧ (សេចក្តីសង្ខេប)

- **មាត្រា ១៖** សៀម ប្រគល់ទឹកដីបាត់ដំបង សៀមរាប និងស៊ីសុផុន ទៅបារាំង។
- **មាត្រា ២៖** បារាំង ប្រគល់ទឹកដីដានសៃ និងត្រាត ព្រមទាំងកោះនានា នៅខាងត្បូងលែមលីង រហូតដល់កោះកូត ទៅសៀម។
- **មាត្រា ៤ និងពិធីសារ៖** ការបង្កើតគណៈកម្មការចម្រុះ ដើម្បីកំណត់ព្រំដែនថ្មី។
- **បទប្បញ្ញត្តិផ្សេងៗ៖** ទាក់ទងនឹងយុត្តាធិការលើប្រជាជនអាស៊ី ក្រោមការការពាររបស់បារាំង នៅសៀម។

### ខ.៣ សេចក្តីសម្រេច (Dispositif) នៃសាលក្រម ICJ ថ្ងៃទី១៥ ខែមិថុនា ឆ្នាំ១៩៦២ (បកប្រែក្រៅផ្លូវការ)

"តុលាការ៖
(១) ដោយសំឡេងប្រាំបួន ទល់នឹងបី សម្រេចថា ប្រាសាទព្រះវិហារ ស្ថិតនៅក្នុងទឹកដីក្រោមអធិបតេយ្យភាពនៃកម្ពុជា
(២) ជាលទ្ធផល ដោយសំឡេងប្រាំបួន ទល់នឹងបី សម្រេចថា ថៃ មានកាតព្វកិច្ច ដកកងកម្លាំងយោធា ឬប៉ូលិស ឬអ្នកយាម ឬអ្នកថែរក្សា ណាមួយ ដែលថៃ បានដាក់នៅប្រាសាទ ឬនៅតំបន់ជុំវិញរបស់វា នៅលើទឹកដីកម្ពុជា
(៣) ដោយសំឡេងប្រាំពីរ ទល់នឹងប្រាំ សម្រេចថា ថៃ មានកាតព្វកិច្ច ប្រគល់មកកម្ពុជាវិញ នូវវត្ថុណាមួយ ក្នុងប្រភេទ ដែលបានបញ្ជាក់ក្នុងការដាក់ពាក្យចុងក្រោយរបស់កម្ពុជា ដែលអាចត្រូវបានយកចេញ ពីប្រាសាទ ឬតំបន់ប្រាសាទ ដោយអាជ្ញាធរថៃ ចាប់តាំងពីថៃ កាន់កាប់ប្រាសាទ នៅឆ្នាំ១៩៥៤។"

### ខ.៤ ចំណុចសំខាន់ៗ នៃដីកាវិធានការបណ្តោះអាសន្ន ICJ ថ្ងៃទី១៨ ខែកក្កដា ឆ្នាំ២០១១

1. បដិសេធសំណើរបស់ថៃ ឱ្យលុបរឿងក្តីចេញពីបញ្ជី (ឯកច្ឆន្ទ)
2. កំណត់តំបន់គ្មានយោធាបណ្តោះអាសន្ន (PDZ) ហើយបញ្ជាឱ្យភាគីទាំងពីរ ដកបុគ្គលិកយោធា ចេញភ្លាមៗ (១១–៥)
3. ថៃ មិនត្រូវរារាំងការចូលដោយសេរីរបស់កម្ពុជា ទៅកាន់ប្រាសាទ (១៥–១)
4. ភាគីទាំងពីរ ត្រូវបន្តសហប្រតិបត្តិការ ក្នុងក្របខណ្ឌអាស៊ាន និងអនុញ្ញាតឱ្យអ្នកសង្កេតការណ៍ ចូលក្នុង PDZ (១៥–១)
5. ភាគីទាំងពីរ ត្រូវជៀសវាងសកម្មភាព ដែលធ្វើឱ្យវិវាទកាន់តែធ្ងន់ធ្ងរ (១៥–១)
6. ភាគីនីមួយៗ ត្រូវរាយការណ៍ ទៅតុលាការ (១៥–១)

### ខ.៥ សេចក្តីសម្រេច នៃសាលដីកា ICJ ថ្ងៃទី១១ ខែវិច្ឆិកា ឆ្នាំ២០១៣ (បកប្រែក្រៅផ្លូវការ)

"តុលាការ ជាឯកច្ឆន្ទ៖
(១) រកឃើញថា ខ្លួនមានយុត្តាធិការ ក្រោមមាត្រា ៦០ នៃលក្ខន្តិកៈ ក្នុងការទទួលយកសំណើបកស្រាយ ដែលដាក់ដោយកម្ពុជា ហើយសំណើនោះ អាចទទួលយកបាន
(២) ប្រកាស ដោយការបកស្រាយ ថាសាលក្រម ថ្ងៃទី១៥ ខែមិថុនា ឆ្នាំ១៩៦២ បានសម្រេចថា កម្ពុជា មានអធិបតេយ្យភាព លើទឹកដីទាំងមូល នៃជ្រោយភ្នំព្រះវិហារ ដូចដែលបានកំណត់ ក្នុងកថាខណ្ឌ ៩៨ នៃសាលដីកានេះ ហើយជាលទ្ធផល ថៃ មានកាតព្វកិច្ច ដកកងកម្លាំងយោធា ឬប៉ូលិស ឬអ្នកយាម ឬអ្នកថែរក្សា ថៃ ដែលត្រូវបានដាក់នៅទីនោះ ចេញពីទឹកដីនោះ។"

### ខ.៦ ចំណុចសំខាន់ៗ នៃ MOU ថ្ងៃទី១៤ ខែមិថុនា ឆ្នាំ២០០០

- **មាត្រា ១៖** ការស្ទង់ និងបោះបង្គោល ផ្អែកលើ៖ (ក) អនុសញ្ញា ១៩០៤ (ខ) សន្ធិសញ្ញា ១៩០៧ និងពិធីសារ (គ) ផែនទី ដែលជាលទ្ធផលនៃការងាររបស់គណៈកម្មការកំណត់ព្រំដែន ឥណ្ឌូចិន–សៀម និង (ឃ) ឯកសារផ្សេងទៀត ទាក់ទងនឹងការអនុវត្ត
- **មាត្រា ២៖** ការបង្កើតគណៈកម្មការព្រំដែនរួម (JBC)
- **មាត្រា ៣៖** ការងារស្ទង់ និងបោះបង្គោល ត្រូវធ្វើឡើង ដោយក្រុមបច្ចេកទេសរួម
- **មាត្រា ៥៖** ក្នុងអំឡុងពេលស្ទង់ និងបោះបង្គោល ភាគីទាំងពីរ មិនត្រូវធ្វើការងារ ដែលបណ្តាលឱ្យមានការផ្លាស់ប្តូរបរិស្ថាន នៃតំបន់ព្រំដែន
- **មាត្រា ៨៖** វិវាទណាមួយ ទាក់ទងនឹងការបកស្រាយ ឬអនុវត្ត MOU ត្រូវដោះស្រាយ ដោយសន្តិវិធី តាមរយៈការពិគ្រោះ និងការចរចា

### ខ.៧ ធម្មនុញ្ញអាស៊ាន — មាត្រាពាក់ព័ន្ធ នឹងការដោះស្រាយវិវាទ

- **មាត្រា ២ (២)(ឃ)៖** ការពឹងផ្អែកលើការដោះស្រាយវិវាទ ដោយសន្តិវិធី
- **មាត្រា ២២៖** រដ្ឋសមាជិក ត្រូវខិតខំដោះស្រាយវិវាទ ទាន់ពេល ដោយសន្តិវិធី តាមរយៈការសន្ទនា ការពិគ្រោះ និងការចរចា
- **មាត្រា ២៣៖** ភាគីវិវាទ អាចស្នើសុំឱ្យប្រធានអាស៊ាន ឬអគ្គលេខាធិការអាស៊ាន ផ្តល់សេវាល្អ ការផ្សះផ្សា ឬការសម្របសម្រួល
- **មាត្រា ២៤៖** វិវាទទាក់ទងនឹងឧបករណ៍ជាក់លាក់ ត្រូវដោះស្រាយ តាមយន្តការ ដែលមានក្នុងឧបករណ៍នោះ (ឧ. TAC)
- **មាត្រា ២៦៖** វិវាទដែលមិនទាន់ដោះស្រាយ អាចត្រូវបានបញ្ជូន ទៅកិច្ចប្រជុំកំពូលអាស៊ាន

| ការកំណត់ព្រំដែន | Delimitation | ការកំណត់ខ្សែព្រំដែន ក្នុងសន្ធិសញ្ញា ឬលើផែនទី |

| សហគមន៍សន្តិសុខ | Security community | ក្រុមរដ្ឋ ដែលមិនគិតពីសង្គ្រាម រវាងគ្នា |
| ភាពមិនអាចបែងចែកបាន | Indivisibility | លក្ខណៈនៃទីតាំង ដែលត្រូវបានយល់ឃើញ ថាមិនអាចបែងចែកបាន |
| ការតាមដានដំណើរការ | Process tracing | វិធីសាស្ត្រវិភាគ យន្តការបុព្វហេតុ |
| អ្នកបំផ្លាញសន្តិភាព | Spoiler | តួអង្គ ដែលបំផ្លាញដំណើរការសន្តិភាព |
| ភាពជាប់គាំងដែលធ្វើឱ្យឈឺចាប់ | Mutually hurting stalemate | ស្ថានភាព ដែលភាគីទាំងពីរ មិនអាចឈ្នះ ហើយរងការខាតបង់ |
| ការការពារហានិភ័យ | Hedging | យុទ្ធសាស្ត្រ រក្សាទំនាក់ទំនង ជាមួយមហាអំណាចច្រើន |
| អន្តរទំនាក់ទំនងជាអាវុធ | Weaponized interdependence | ការប្រើប្រាស់ការពឹងផ្អែកសេដ្ឋកិច្ច ដើម្បីបង្ខិតបង្ខំ |
| ការទូតពន្ធគយ | Tariff diplomacy | ការប្រើប្រាស់គោលនយោបាយពន្ធគយ ជាឧបករណ៍ការទូត |
| ការទូតដឹកជញ្ជូន | Shuttle diplomacy | ការសម្របសម្រួល ដោយធ្វើដំណើររវាងភាគី |
| គ្រាប់មិនទាន់ផ្ទុះ | Unexploded ordnance (UXO) | គ្រាប់ ដែលមិនទាន់ផ្ទុះ ក្រោយការបាញ់ |
| គ្រាប់បែកចង្កោម | Cluster munitions | គ្រាប់បែក ដែលបញ្ចេញគ្រាប់តូចៗ ជាច្រើន |
| ឧទ្យានសន្តិភាព | Peace park | តំបន់អភិរក្សឆ្លងដែន ដែលលើកកម្ពស់សហប្រតិបត្តិការ |
| ជ្រោយភ្នំ | Promontory | ផ្នែកភ្នំ ដែលលយចេញ |

| រូបកាយភូមិសាស្ត្រ | Geo-body | រូបរាងទឹកដីជាតិ ដែលមានព្រំដែនច្បាស់លាស់ (Thongchai) |

## ឧបសម្ព័ន្ធ ឃ៖ ទម្រង់សំណួរសម្ភាសន៍ពាក់កណ្តាលរចនាសម្ព័ន្ធ

### ឃ.១ សេចក្តីណែនាំសម្រាប់អ្នកសម្ភាសន៍

- ពន្យល់ពីគោលបំណងស្រាវជ្រាវ សិទ្ធិរបស់អ្នកចូលរួម (ការដកខ្លួន ការរក្សាការសម្ងាត់) ហើយទទួលការយល់ព្រមជាលាយលក្ខណ៍អក្សរ ឬផ្ទាល់មាត់ (ថតសំឡេង)។
- សួរសំណួរបើកចំហ ហើយអនុញ្ញាតឱ្យអ្នកចូលរួម និយាយដោយសេរី។
- ជៀសវាងសំណួរដែលនាំមុខ (leading questions) ឬសំណួរ ដែលអាចបង្កគ្រោះថ្នាក់ ដល់អ្នកចូលរួម។
- រយៈពេលប៉ាន់ស្មាន៖ ៤៥–៩០ នាទី។

### ឃ.២ សំណួរសម្រាប់អតីតមន្ត្រីការទូត និងអ្នកជំនាញព្រំដែន

1. តាមបទពិសោធន៍របស់លោក/លោកស្រី តើបញ្ហាប្រឈមចម្បង ក្នុងការងារបោះបង្គោលព្រំដែន កម្ពុជា–ថៃ គឺអ្វីខ្លះ?
2. តើ MOU ឆ្នាំ២០០០ មានតួនាទី និងដែនកំណត់អ្វីខ្លះ?
3. តើទំនាក់ទំនងផ្ទាល់ខ្លួន រវាងថ្នាក់ដឹកនាំ មានឥទ្ធិពលប៉ុណ្ណា លើការចរចាព្រំដែន?
4. តើលោក/លោកស្រី វាយតម្លៃតួនាទីរបស់អាស៊ាន ក្នុងវិបត្តិឆ្នាំ២០១១ និង ២០២៥ យ៉ាងដូចម្តេច?
5. តើយន្តការអ្វី ដែលអាចជួយការពារការកើតឡើងវិញ នៃអរិភាព?

### ឃ.៣ សំណួរសម្រាប់អ្នកប្រាជ្ញ និងអ្នកវិភាគ

1. តើកត្តាអ្វីខ្លះ ដែលលោក/លោកស្រី គិតថា សំខាន់បំផុត ក្នុងការពន្យល់ពីសង្គ្រាមឆ្នាំ២០២៥?
2. តើនយោបាយក្នុងស្រុក នៃប្រទេសនីមួយៗ មានតួនាទីអ្វី?
3. តើលោក/លោកស្រី យល់ឃើញយ៉ាងណា ចំពោះតួនាទីរបស់សហរដ្ឋអាមេរិក និងចិន?
4. តើកិច្ចព្រមព្រៀងកូឡាឡាំពួរ មានចំណុចខ្លាំង និងខ្សោយអ្វីខ្លះ?
5. តើគំនិត "ឧទ្យានសន្តិភាព" ឬការគ្រប់គ្រងបេតិកភណ្ឌរួម អាចអនុវត្តបាន ឬទេ? ហេតុអ្វី?

### ឃ.៤ សំណួរសម្រាប់អ្នកសារព័ត៌មាន

1. តើការរាយការណ៍ពីតំបន់ព្រំដែន ក្នុងអំឡុងសង្គ្រាម មានបញ្ហាប្រឈមអ្វីខ្លះ?
2. តើព័ត៌មានក្លែងក្លាយ និងបណ្តាញសង្គម មានឥទ្ធិពលយ៉ាងដូចម្តេច លើមតិសាធារណៈ?
3. តើប្រព័ន្ធផ្សព្វផ្សាយ អាចដើរតួនាទីអ្វី ក្នុងការលើកកម្ពស់សន្តិភាព?

### ឃ.៥ សំណួរសម្រាប់ប្រជាជនរងផលប៉ះពាល់ និងបុគ្គលិកមនុស្សធម៌

1. សូមរៀបរាប់ពីបទពិសោធន៍របស់លោក/លោកស្រី ក្នុងអំឡុងពេលនៃការប្រយុទ្ធ និងការជម្លៀស (ប្រសិនបើយល់ព្រមចែករំលែក)។
2. តើជីវភាពរបស់លោក/លោកស្រី បានផ្លាស់ប្តូរយ៉ាងដូចម្តេច ក្រោយវិបត្តិ?
3. មុនវិបត្តិ តើទំនាក់ទំនងជាមួយប្រជាជន នៅម្ខាងទៀតនៃព្រំដែន យ៉ាងដូចម្តេច?
4. តើលោក/លោកស្រី ត្រូវការអ្វីខ្លះ ដើម្បីស្តារជីវភាពឡើងវិញ?
5. តើលោក/លោកស្រី មានសារអ្វី ចង់ផ្ញើទៅកាន់មេដឹកនាំ នៃប្រទេសទាំងពីរ?

*(កំណត់សម្គាល់៖ ការសម្ភាសន៍ជាមួយជនរងគ្រោះ ត្រូវធ្វើឡើងដោយប្រុងប្រយ័ត្នខ្ពស់ ស្របតាមគោលការណ៍ "មិនបង្កគ្រោះថ្នាក់" និងជាមួយការគាំទ្រផ្លូវចិត្ត ប្រសិនបើចាំបាច់)*
