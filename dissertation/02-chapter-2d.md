
## ២.១៣ ទ្រឹស្តីរដ្ឋតូច (Small State Theory)

### ២.១៣.១ និយមន័យ និងលក្ខណៈ

ការសិក្សាអំពី "រដ្ឋតូច" (small states) បានក្លាយជាវិស័យរង មួយ ដ៏សំខាន់ ក្នុងទំនាក់ទំនងអន្តរជាតិ។ ទោះបីជាគ្មាននិយមន័យ តែមួយ ដែលទទួលយក ជាសកល — អ្នកស្រាវជ្រាវខ្លះ ប្រើលក្ខណៈវិនិច្ឆ័យ បរិមាណ (ចំនួនប្រជាជន ទំហំសេដ្ឋកិច្ច កម្លាំងយោធា) ខ្លះទៀត ប្រើលក្ខណៈវិនិច្ឆ័យ ទំនាក់ទំនង (relational) — ក៏គំនិតស្នូល គឺថា រដ្ឋតូច ជារដ្ឋ ដែលមិនអាចធានាសន្តិសុខ របស់ខ្លួន តែឯងបាន ដោយពឹងផ្អែក លើសមត្ថភាពផ្ទាល់ខ្លួន ហើយដូច្នេះ ត្រូវតែពឹងផ្អែក លើទំនាក់ទំនង ស្ថាប័ន និងបទដ្ឋាន អន្តរជាតិ (Keohane, 1969)។ ក្នុងទំនាក់ទំនង ជាមួយប្រទេសថៃ កម្ពុជា បំពេញលក្ខណៈវិនិច្ឆ័យ ទំនាក់ទំនង នៃ "រដ្ឋតូច" — ទោះបីជាក្នុងបរិបទផ្សេង (ឧ. ធៀបនឹងរដ្ឋកោះតូចៗ) កម្ពុជា ប្រហែលជាមិនត្រូវបានចាត់ទុក ជារដ្ឋតូច ក៏ដោយ។

### ២.១៣.២ យុទ្ធសាស្ត្រ របស់រដ្ឋតូច

អក្សរសិល្ប៍ អំពីរដ្ឋតូច បានកំណត់ យុទ្ធសាស្ត្រ សំខាន់ៗ ដែលរដ្ឋតូច ប្រើប្រាស់ ដើម្បីការពារផលប្រយោជន៍ របស់ខ្លួន ក្នុងទំនាក់ទំនង ជាមួយរដ្ឋធំ៖

1. **ការស្វែងរកទីជម្រក (Shelter-seeking)៖** រដ្ឋតូច ស្វែងរក "ទីជម្រក" ផ្នែកនយោបាយ សេដ្ឋកិច្ច និងសង្គម ពីមហាអំណាច ឬអង្គការអន្តរជាតិ (Thorhallsson, 2018)។ ក្នុងករណីកម្ពុជា ទំនាក់ទំនងជិតស្និទ្ធ ជាមួយចិន និងការពឹងផ្អែកលើអាស៊ាន គឺជាឧទាហរណ៍ នៃយុទ្ធសាស្ត្រនេះ។
2. **ការពង្រឹងស្ថាប័ន និងច្បាប់ (Institutional Binding)៖** រដ្ឋតូច គាំទ្រ និងពឹងផ្អែកលើ ច្បាប់អន្តរជាតិ និងស្ថាប័នពហុភាគី ដែលកំណត់ ឥរិយាបថ របស់រដ្ឋធំ ហើយផ្តល់ "សមភាពផ្លូវការ" ដល់រដ្ឋទាំងអស់ — ដូចការប្តឹងរបស់កម្ពុជា ទៅ ICJ។
3. **ការការពារហានិភ័យ (Hedging)៖** រដ្ឋតូច រក្សាទំនាក់ទំនង ជាមួយមហាអំណាចច្រើន ដើម្បីជៀសវាងការពឹងផ្អែក លើមហាអំណាចតែមួយ — ដូចការពង្រឹងទំនាក់ទំនង របស់កម្ពុជា ជាមួយសហរដ្ឋអាមេរិក ក្នុងឆ្នាំ២០២៥ ខណៈរក្សាទំនាក់ទំនង ជិតស្និទ្ធ ជាមួយចិន។
4. **ការទូតជាសាធារណៈ និងអំណាចសីលធម៌ (Moral Power)៖** រដ្ឋតូច ប្រើប្រាស់ ការទូតសាធារណៈ និងការអំពាវនាវ ទៅកាន់គោលការណ៍ សីលធម៌ (យុត្តិធម៌ ច្បាប់ សិទ្ធិ) ដើម្បីទាក់ទាញ ការគាំទ្រ ពីសហគមន៍អន្តរជាតិ — ដូចនិទានកថា "រដ្ឋតូច ការពារខ្លួន ពីរដ្ឋធំ" របស់កម្ពុជា ក្នុងឆ្នាំ២០២៥។
5. **ការបង្កើនការចំណាយ (Raising Costs)៖** រដ្ឋតូច មិនអាចឈ្នះសង្គ្រាម ប្រឆាំងនឹងរដ្ឋធំ ប៉ុន្តែអាចបង្កើន "ការចំណាយ" នៃការឈ្លានពាន តាមរយៈការការពារ យ៉ាងរឹងមាំ — ដែលធ្វើឱ្យរដ្ឋធំ ស្ទាក់ស្ទើរ ក្នុងការប្រើប្រាស់កម្លាំង។

### ២.១៣.៣ ការអនុវត្ត និងដែនកំណត់

ទ្រឹស្តីរដ្ឋតូច ពន្យល់ បានល្អ អំពីយុទ្ធសាស្ត្រ របស់កម្ពុជា ក្នុងជម្លោះ — ការផ្តោតលើច្បាប់អន្តរជាតិ ការអន្តរជាតូបនីយកម្ម ការស្វែងរកការគាំទ្រ ពីមហាអំណាច និងអង្គការតំបន់ និងការការពារ ទីតាំង យ៉ាងរឹងមាំ។ ទោះជាយ៉ាងណា ទ្រឹស្តីនេះ ក៏បង្ហាញពី "បញ្ហាលំបាក" មួយចំនួន របស់រដ្ឋតូច៖ (ក) ការពឹងផ្អែក លើមហាអំណាចមួយ (ឧ. ចិន) អាចធ្វើឱ្យមហាអំណាចមួយទៀត (ឧ. សហរដ្ឋអាមេរិក) និងប្រទេសជិតខាង មានការសង្ស័យ (ខ) យុទ្ធសាស្ត្រ អន្តរជាតូបនីយកម្ម អាចត្រូវបានរដ្ឋធំ យល់ឃើញ ថាជាការប្រជែង ហើយបង្កើនភាពតានតឹង ក្នុងរយៈពេលខ្លី (សូមមើលការវិភាគ "ប្រសិនបើ" ក្នុងជំពូកទី១០) និង (គ) ស្ថាប័នអន្តរជាតិ ផ្តល់ការការពារ តែក្នុងកម្រិត ដែលរដ្ឋធំ យល់ព្រម ទទួលយក — ដូចការបដិសេធ យុត្តាធិការ ICJ របស់ថៃ បានបង្ហាញ។

## ២.១៤ ទ្រឹស្តីការកើនឡើង នៃជម្លោះ (Escalation Theory)

### ២.១៤.១ "ជណ្តើរ នៃការកើនឡើង" របស់ Kahn

លោក Herman Kahn (1965) នៅក្នុង *On Escalation: Metaphors and Scenarios* បានស្នើគំនិត "ជណ្តើរ នៃការកើនឡើង" (escalation ladder) — ជាជំហាន ជាលំដាប់ ពីវិបត្តិផ្នែកនយោបាយ រហូតដល់សង្គ្រាម ពេញលេញ។ ទោះបីជាគំនិតនេះ ត្រូវបានអភិវឌ្ឍ ក្នុងបរិបទ នៃសង្គ្រាមត្រជាក់ និងអាវុធនុយក្លេអ៊ែរ ក៏គំនិតស្នូល — ថាការកើនឡើង កើតឡើង ជាជំហាន ហើយជំហាននីមួយៗ មាន "កម្រិត" (thresholds) ដែលពិបាកឆ្លងកាត់ ត្រឡប់ក្រោយ — មានប្រយោជន៍ សម្រាប់ការវិភាគ ជម្លោះកម្រិតទាប និងមធ្យម ផងដែរ។

### ២.១៤.២ ជណ្តើរ នៃការកើនឡើង សម្រាប់ជម្លោះកម្ពុជា–ថៃ

ផ្អែកលើគំនិតរបស់ Kahn និងទិន្នន័យ ពីវិបត្តិ ទាំងបី និក្ខេបបទនេះ ស្នើ "ជណ្តើរ នៃការកើនឡើង" ជាក់លាក់ សម្រាប់ជម្លោះកម្ពុជា–ថៃ៖

| ជំហាន | ការពិពណ៌នា | ឧទាហរណ៍ |
|---|---|---|
| ១ | ភាពតានតឹងផ្នែកសុន្ទរកថា | ការប្រកួតប្រជែងវប្បធម៌ នៅលើបណ្តាញសង្គម (២០២៣–២០២៤) |
| ២ | ឧប្បត្តិហេតុនិមិត្តរូប ក្នុងតំបន់ | ការច្រៀងបទចម្រៀងជាតិ នៅតាមាន់ធំ (កុម្ភៈ ២០២៥) |
| ៣ | ការប៉ះទង្គិចយោធា តូច | ការប៉ះទង្គិចមុំបី (ឧសភា ២០២៥) |
| ៤ | ការពង្រឹងកងកម្លាំង និងវិធានការការទូត | ការប្រមូលផ្តុំកងកម្លាំង ការប្រកាសទៅ ICJ (មិថុនា ២០២៥) |
| ៥ | វិធានការសេដ្ឋកិច្ច | ការបិទព្រំដែន ការហាមឃាត់ (មិថុនា ២០២៥) |
| ៦ | វិបត្តិនយោបាយក្នុងស្រុក | ការលេចធ្លាយ ការដួលរលំរដ្ឋាភិបាល (មិថុនា–កក្កដា ២០២៥) |
| ៧ | ការបន្ថយទំនាក់ទំនងការទូត | ការបណ្តេញឯកអគ្គរាជទូត (២៣ កក្កដា ២០២៥) |
| ៨ | ការប្រយុទ្ធ ដោយអាវុធធុនធ្ងន់ ក្នុងតំបន់ | កាំភ្លើងធំ រ៉ុក្កែត (២៤ កក្កដា ២០២៥) |
| ៩ | ការប្រើប្រាស់កម្លាំងអាកាស | F-16 (២៤ កក្កដា ២០២៥) |
| ១០ | ការរីករាលដាលភូមិសាស្ត្រ | ការប្រយុទ្ធ នៅតំបន់ភាគខាងត្បូង (២៦ កក្កដា ២០២៥) |
| ១១ | សង្គ្រាមពេញលេញ (ការវាយលុកជ្រៅ ការវាយប្រហារទីក្រុងធំ) | *មិនបានកើតឡើង* |

### ២.១៤.៣ អត្ថន័យ សម្រាប់ការវិភាគ

ការប្រើប្រាស់ជណ្តើរ នៃការកើនឡើង ជួយបង្ហាញពីចំណុចសំខាន់ៗ ពីរ ដែលនឹងត្រូវវិភាគ លម្អិត នៅជំពូកបន្តបន្ទាប់៖

**ទីមួយ — ល្បឿន នៃការកើនឡើង៖** ក្នុងឆ្នាំ២០២៥ ជម្លោះ បានឡើង ពីជំហានទី៣ ទៅជំហានទី១០ ក្នុងរយៈពេល តិចជាងពីរខែ — លឿនជាងវិបត្តិ ២០០៨–២០១១ ច្រើន (ដែលត្រូវការរយៈពេល ជិតបីឆ្នាំ ដើម្បីឈានដល់ជំហានទី៨)។ ល្បឿននេះ ឆ្លុះបញ្ចាំងពីការបាត់បង់ "ហ្វ្រាំង" (ទំនាក់ទំនងឥស្សរជន និងរដ្ឋាភិបាលស៊ីវិល ថៃ ដែលមានសិទ្ធិអំណាច) និងតួនាទី នៃបណ្តាញសង្គម ក្នុងការពន្លឿន ការកំណត់សន្តិសុខ។

**ទីពីរ — កម្រិត ដែលមិនត្រូវបានឆ្លងកាត់៖** ទោះបីជាមានការកើនឡើង យ៉ាងឆាប់រហ័ស ក៏ជម្លោះ មិនបានឈានដល់ជំហានទី១១ (សង្គ្រាមពេញលេញ) ឡើយ។ ការពិតនេះ បង្ហាញពីវត្តមាន នៃកត្តាទប់ស្កាត់ — ការពឹងផ្អែកសេដ្ឋកិច្ច សម្ពាធពីខាងក្រៅ បទដ្ឋានអាស៊ាន និងការគណនា របស់មេដឹកនាំ — ដែលនឹងត្រូវពិភាក្សា នៅជំពូកទី៨ និងទី១១។ ការយល់ដឹង អំពីកត្តាទាំងនេះ មានសារៈសំខាន់ សម្រាប់ការការពារ ការកើនឡើង នាពេលអនាគត។

**ទីបី — ការចុះពីជណ្តើរ (De-escalation)៖** ជណ្តើរ នៃការកើនឡើង ក៏អាចប្រើប្រាស់ ដើម្បីវិភាគ ការចុះពីជណ្តើរ ផងដែរ។ បទឈប់បាញ់ពុត្រាចាយ៉ា បាននាំជម្លោះ ពីជំហានទី១០ មកជំហានទី៤–៥ ភ្លាមៗ ប៉ុន្តែមិនបាននាំវា ចុះដល់ជំហានទី១–២ ទេ — វិធានការសេដ្ឋកិច្ច ការបន្ថយទំនាក់ទំនងការទូត និងការដាក់ពង្រាយកងកម្លាំង នៅតែបន្ត។ ការពិតដែលថា ជម្លោះ "ជាប់គាំង" នៅជំហានកណ្តាល ពន្យល់ពីភាពងាយស្រួល នៃការវិលត្រឡប់ ទៅជំហានខ្ពស់ នៅខែធ្នូ — ព្រោះចម្ងាយ ពីជំហានទី៥ ទៅជំហានទី៨ ខ្លីជាង ពីជំហានទី១។

## សេចក្តីសន្និដ្ឋានជំពូក

ជំពូកនេះ បានបង្ហាញថា គ្មានទ្រឹស្តីតែមួយ អាចពន្យល់ជម្លោះកម្ពុជា–ថៃ បានគ្រប់គ្រាន់នោះទេ។ ប្រាកដនិយម ពន្យល់ពីយុទ្ធសាស្ត្ររបស់រដ្ឋ ក្នុងបរិបទអតុល្យភាពអំណាច។ ស្ថាបនានិយម ពន្យល់ពីមូលហេតុដែលដែនដីតូចមួយ អាចមានតម្លៃដ៏ធំធេង។ ទ្រឹស្តីសង្គ្រាមបង្វែរអារម្មណ៍ ពន្យល់ពីពេលវេលានៃការផ្ទុះជម្លោះ។ ច្បាប់អន្តរជាតិ ផ្តល់ក្របខណ្ឌសម្រាប់ដោះស្រាយ ប៉ុន្តែមានដែនកំណត់។ ទ្រឹស្តីសហគមន៍សន្តិសុខ ផ្តល់មូលដ្ឋាន សម្រាប់វាយតម្លៃតួនាទីរបស់អាស៊ាន។ ទ្រឹស្តីភាពទុំ និងការសម្របសម្រួល ពន្យល់ពីពេលវេលា និងលក្ខណៈ នៃបទឈប់បាញ់ ហើយទ្រឹស្តីបំប្លែងជម្លោះ ការសិក្សាព្រំដែន និងការសិក្សាបេតិកភណ្ឌ ផ្តល់មូលដ្ឋាន សម្រាប់ការរចនាដំណោះស្រាយយូរអង្វែង។ ក្របខណ្ឌ "ត្រីកោណជម្លោះ" ដែលបានស្នើ នឹងត្រូវប្រើប្រាស់ ជាឧបករណ៍វិភាគចម្បង នៅក្នុងជំពូកបន្តបន្ទាប់។
