
## ៣.៦ ការប្រតិបត្តិនូវអថេរ និងគ្រោងការណ៍កូដ

### ៣.៦.១ ការប្រតិបត្តិនូវអថេរ (Operationalization)

ដើម្បីធ្វើតេស្តសម្មតិកម្ម ដោយមានភាពម៉ត់ចត់ អថេរនីមួយៗ ក្នុងក្របខណ្ឌ "ត្រីកោណជម្លោះ" ត្រូវបានកំណត់ ជាប្រតិបត្តិការ ដូចតទៅ៖

| អថេរ | និយមន័យប្រតិបត្តិការ | សូចនាករ | ប្រភពទិន្នន័យ |
|---|---|---|---|
| **កម្រិតជម្លោះ** (អថេរអាស្រ័យ) | កម្រិតខ្ពស់បំផុត នៃអរិភាព ក្នុងរយៈពេលកំណត់ | មាត្រដ្ឋាន ០–៥៖ ០=គ្មានភាពតានតឹង ១=ភាពតានតឹងការទូត ២=វិធានការសេដ្ឋកិច្ច/ការបិទព្រំដែន ៣=ការប៉ះទង្គិចកម្រិតទាប (<១០ ស្លាប់) ៤=ការប៉ះទង្គិចកម្រិតមធ្យម (១០–២៥ ស្លាប់) ៥=សង្គ្រាមកម្រិតខ្ពស់ (>២៥ ស្លាប់ ឬការប្រើប្រាស់កម្លាំងអាកាស) | របាយការណ៍សារព័ត៌មាន UCDP ACLED |
| **ភាពមិនស្ថិតស្ថេរនយោបាយថៃ** (H1) | កម្រិតនៃការប្រកួតប្រជែង ដែលគំរាមកំហែងរដ្ឋាភិបាល | ការមានបាតុកម្មធំ (>១០,០០០ នាក់) ញត្តិទៅតុលាការរដ្ឋធម្មនុញ្ញ ប្រឆាំងនាយករដ្ឋមន្ត្រី ការដកខ្លួនចេញពីរដ្ឋាភិបាលចម្រុះ រដ្ឋប្រហារ | សារព័ត៌មាន ការសិក្សាសិក្សាធិការ |
| **ការប្រើប្រាស់បញ្ហាព្រំដែន ក្នុងនយោបាយក្នុងស្រុក** (H1) | ការលើកឡើងបញ្ហាព្រំដែន ដោយតួអង្គនយោបាយ ដើម្បីវាយប្រហារគូប្រជែង | ចំនួនសេចក្តីថ្លែងការណ៍ ញត្តិ បាតុកម្ម ដែលភ្ជាប់បញ្ហាកម្ពុជា ជាមួយការរិះគន់រដ្ឋាភិបាល | ការវិភាគខ្លឹមសារ |
| **ដំណោះស្រាយច្បាប់** (H2) | វត្តមាន នៃការសម្រេចផ្នែកច្បាប់ ដែលមានកាតព្វកិច្ចចង | សាលក្រម/ដីកា ICJ ការអនុវត្ត | ឯកសារ ICJ |
| **គុណភាពទំនាក់ទំនងឥស្សរជន** (H3) | កម្រិតនៃទំនាក់ទំនងផ្ទាល់ខ្លួន រវាងមេដឹកនាំ | មាត្រដ្ឋាន ១–៣៖ ១=អរិភាព (ការរិះគន់ជាសាធារណៈ) ២=អព្យាក្រឹត ៣=ជិតស្និទ្ធ (ការជួបជាប្រចាំ ការលើកឡើងជាមិត្ត) | សុន្ទរកថា សារព័ត៌មាន |
| **ការចូលរួមភាគីទីបី** (H4) | កម្រិតនៃការអន្តរាគមន៍ ពីអាស៊ាន មហាអំណាច អង្គការអន្តរជាតិ | ប្រភេទ (សេចក្តីថ្លែងការណ៍ ការសម្របសម្រួល ការដាក់ពង្រាយអ្នកសង្កេតការណ៍ ការប្រើប្រាស់ឥទ្ធិពល) និងកម្រិតថ្នាក់ (រដ្ឋមន្ត្រី ថ្នាក់ដឹកនាំកំពូល) | ឯកសារផ្លូវការ សារព័ត៌មាន |

### ៣.៦.២ គ្រោងការណ៍កូដ សម្រាប់ការវិភាគខ្លឹមសារ

ការវិភាគខ្លឹមសារ នៃសេចក្តីថ្លែងការណ៍ផ្លូវការ និងអត្ថបទសារព័ត៌មាន (ជំពូកទី៧ ផ្នែក ៧.៧) ប្រើប្រាស់គ្រោងការណ៍កូដ (coding scheme) ដែលមានប្រភេទ ដូចតទៅ៖

| កូដ | ប្រភេទ | ឧទាហរណ៍ នៃពាក្យ/ឃ្លា |
|---|---|---|
| SOV | អធិបតេយ្យភាព និងបូរណភាពទឹកដី | "អធិបតេយ្យភាព" "ទឹកដីជាតិ" "បូរណភាពទឹកដី" "មិនបោះបង់" |
| LAW | ច្បាប់អន្តរជាតិ | "ច្បាប់អន្តរជាតិ" "ICJ" "សាលក្រម" "សន្ធិសញ្ញា" "អនុសញ្ញា" |
| AGG | ការឈ្លានពាន/ការគំរាមកំហែង | "ឈ្លានពាន" "វាយប្រហារ" "បង្កហេតុ" "រំលោភ" |
| DEF | ការការពារខ្លួន | "ការពារខ្លួន" "តបត" "មាត្រា ៥១" |
| VIC | ការរងគ្រោះ | "ជនរងគ្រោះ" "ជនស៊ីវិល" "កុមារ" "មន្ទីរពេទ្យ" |
| HER | បេតិកភណ្ឌ | "ប្រាសាទ" "បេតិកភណ្ឌ" "យូណេស្កូ" "ដូនតា" |
| UNI | ការរួបរួមជាតិ | "រួបរួម" "សាមគ្គី" "ស្នេហាជាតិ" |
| TRA | ការក្បត់ | "ក្បត់ជាតិ" "លក់ទឹកដី" "ផលប្រយោជន៍គ្រួសារ" |
| PEA | សន្តិភាព និងការចរចា | "សន្តិភាព" "ចរចា" "បទឈប់បាញ់" "សន្តិវិធី" |
| INT | អន្តរជាតូបនីយកម្ម | "សហគមន៍អន្តរជាតិ" "អាស៊ាន" "អង្គការសហប្រជាជាតិ" |
| BIL | ទ្វេភាគីភាព | "ទ្វេភាគី" "JBC" "GBC" "មិនជ្រៀតជ្រែក" |
| MIN | មីន | "មីន" "អូតាវ៉ា" "គ្រាប់មិនទាន់ផ្ទុះ" |
| CRM | ឧក្រិដ្ឋកម្ម | "បោកប្រាស់" "ឧក្រិដ្ឋកម្ម" "កាស៊ីណូ" "ជួញដូរ" |

អត្ថបទ នីមួយៗ ត្រូវបានកូដ ដោយផ្អែកលើប្រធានបទលេចធ្លោ (dominant frame) និងប្រធានបទបន្ទាប់បន្សំ។ ដើម្បីធានាភាពជឿជាក់ អត្ថបទមួយផ្នែក (ប្រមាណ ២០%) ត្រូវបានកូដ ដោយអ្នកកូដពីរនាក់ ដោយឯករាជ្យ ហើយភាពស្របគ្នា រវាងអ្នកកូដ (inter-coder reliability) ត្រូវបានវាស់ ដោយប្រើប្រាស់ Cohen's kappa។ *(កំណត់សម្គាល់៖ អ្នកស្រាវជ្រាវ ត្រូវរាយការណ៍ ទំហំសំណាក និងតម្លៃ kappa ពិតប្រាកដ ក្នុងកំណែចុងក្រោយ។)*

### ៣.៦.៣ ការរៀបចំកាលប្បវត្តិ (Event Data)

សម្រាប់ការតាមដានដំណើរការ មូលដ្ឋានទិន្នន័យព្រឹត្តិការណ៍ (event dataset) ត្រូវបានរៀបចំ ដោយកត់ត្រា ព្រឹត្តិការណ៍នីមួយៗ ជាមួយព័ត៌មាន ដូចតទៅ៖ កាលបរិច្ឆេទ ទីតាំង (ខេត្ត ស្រុក ភូមិ/ប្រាសាទ) ប្រភេទព្រឹត្តិការណ៍ (យោធា ការទូត សេដ្ឋកិច្ច នយោបាយក្នុងស្រុក) តួអង្គ ការពិពណ៌នា ការបាត់បង់ (ប្រសិនបើមាន) ប្រភព (យ៉ាងហោចណាស់ពីរប្រភព សម្រាប់ព្រឹត្តិការណ៍សំខាន់ៗ) និងកម្រិតនៃការផ្ទៀងផ្ទាត់ (បានផ្ទៀងផ្ទាត់ / ការអះអាងរបស់ភាគីតែមួយ / មានការជំទាស់)។ មូលដ្ឋានទិន្នន័យនេះ គឺជាមូលដ្ឋាន សម្រាប់កាលប្បវត្តិ ក្នុងឧបសម្ព័ន្ធ ក។

## ៣.៧ ដំណើរការស្រាវជ្រាវ និងកាលវិភាគ

ការស្រាវជ្រាវ ត្រូវបានអនុវត្ត ជាដំណាក់កាល៖

| ដំណាក់កាល | សកម្មភាព | លទ្ធផល |
|---|---|---|
| ១. ការរៀបចំ | ការពិនិត្យឯកសារ ការអភិវឌ្ឍក្របខណ្ឌទ្រឹស្តី ការរចនាវិធីសាស្ត្រ ការស្នើសុំការអនុម័តក្រមសីលធម៌ | សំណើស្រាវជ្រាវ ជំពូក ១–៣ |
| ២. ការប្រមូលទិន្នន័យឯកសារ | ការប្រមូលឯកសារច្បាប់ ផ្លូវការ សារព័ត៌មាន ការរៀបចំមូលដ្ឋានទិន្នន័យព្រឹត្តិការណ៍ | មូលដ្ឋានទិន្នន័យ កាលប្បវត្តិ |
| ៣. ការវិភាគ | ការតាមដានដំណើរការ ការវិភាគខ្លឹមសារ និងសុន្ទរកថា ការវិភាគច្បាប់ | ជំពូក ៤–៩ |
| ៤. ការសម្ភាសន៍ (បំពេញបន្ថែម) | ការសម្ភាសន៍ ពាក់កណ្តាលរចនាសម្ព័ន្ធ ការចម្លង ការវិភាគ | ការផ្ទៀងផ្ទាត់ និងការពង្រឹង ការរកឃើញ |
| ៥. ការសំយោគ | ការធ្វើតេស្តសម្មតិកម្ម ការប្រៀបធៀប ការអភិវឌ្ឍក្របខណ្ឌសន្តិភាព | ជំពូក ១០–១២ |
| ៦. ការពិនិត្យ និងកែសម្រួល | ការពិនិត្យដោយសាស្ត្រាចារ្យដឹកនាំ និងមិត្តរួមការងារ ការផ្ទៀងផ្ទាត់តួលេខ និងឯកសារយោង | និក្ខេបបទចុងក្រោយ |

## ៣.៨ ការគ្រប់គ្រងទិន្នន័យ

ទិន្នន័យទាំងអស់ — ឯកសារ ការថតសំឡេងសម្ភាសន៍ កំណត់ត្រា និងមូលដ្ឋានទិន្នន័យ — ត្រូវបានរក្សាទុក ដោយសុវត្ថិភាព ក្នុងទម្រង់ឌីជីថល ដែលមានការការពារ ដោយពាក្យសម្ងាត់ និងការចម្លងទុក (backup)។ ការថតសំឡេងសម្ភាសន៍ និងការចម្លង ដែលមានព័ត៌មានផ្ទាល់ខ្លួន ត្រូវបានរក្សាទុក ដាច់ដោយឡែក ពីទិន្នន័យដែលបានធ្វើអនាមិក ហើយនឹងត្រូវបានលុបចោល ក្រោយរយៈពេលកំណត់ ស្របតាមគោលការណ៍ របស់គណៈកម្មាធិការក្រមសីលធម៌។ មូលដ្ឋានទិន្នន័យព្រឹត្តិការណ៍ (ដែលផ្អែកលើប្រភពសាធារណៈ) អាចត្រូវបានចែករំលែក ជាមួយអ្នកស្រាវជ្រាវផ្សេងទៀត ដើម្បីលើកកម្ពស់តម្លាភាព និងការធ្វើឡើងវិញ (replicability)។

## សេចក្តីសន្និដ្ឋានជំពូក

ជំពូកនេះ បានពន្យល់ពីវិធីសាស្ត្រគុណវិស័យ ដែលផ្អែកលើទស្សនវិជ្ជាប្រាកដនិយមរិះគន់ ការរចនាករណីសិក្សាដែលមានករណីរងច្រើន និងបច្ចេកទេសវិភាគសំខាន់ៗ — ការតាមដានដំណើរការ ការវិភាគសុន្ទរកថា និងការវិភាគច្បាប់។ វិធីសាស្ត្រទាំងនេះ នឹងត្រូវអនុវត្តនៅក្នុងជំពូកទី៤ ដល់ទី១១ ដើម្បីឆ្លើយសំណួរស្រាវជ្រាវ និងធ្វើតេស្តសម្មតិកម្ម។
