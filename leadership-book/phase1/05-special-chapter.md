# ៥. មាតិកាជំពូកពិសេសលម្អិត

## ជំពូក ៩ — មរតកវប្បធម៌នៃការដឹកនាំខ្មែរ៖ ការបន្ត ការប្រែប្រួល និងឥទ្ធិពលពីអតីតកាលដល់បច្ចុប្បន្ន (៥០,០០០ ពាក្យ)

### ៥.១ ការកំណត់ព្រំដែន និងគោលការណ៍

**និយមន័យបឋមនៃ «វប្បធម៌នៃការដឹកនាំ»៖** សំណុំគំនិត ជំនឿ គុណតម្លៃ និមិត្តរូប ពិធី និងការអនុវត្តដែលបានរៀន ដែលកំណត់ការរំពឹងទុករបស់សង្គមចំពោះអ្នកដឹកនាំ និងរបៀបដែលអ្នកដឹកនាំបង្ហាញ និងប្រើអំណាច។ វាខុសពី៖

| គំនិត | ភាពខុសគ្នា |
|---|---|
| ចរិតបុគ្គល | វប្បធម៌ជាអ្វីដែលមនុស្សច្រើនជំនាន់ចែករំលែក មិនមែនលក្ខណៈរបស់មនុស្សម្នាក់ |
| រចនាសម្ព័ន្ធស្ថាប័ន | ស្ថាប័នជាច្បាប់ និងអង្គការ។ វប្បធម៌ជាអត្ថន័យ និងការរំពឹងទុកដែលនៅជុំវិញវា |
| យុទ្ធសាស្ត្រនយោបាយ | យុទ្ធសាស្ត្រជាការជ្រើសរើសដោយចេតនា។ ការប្រើនិមិត្តរូបវប្បធម៌ជាយុទ្ធសាស្ត្រ ត្រូវបែងចែកពីការបន្តវប្បធម៌ពិតប្រាកដ |

**ព្រំដែនសម័យ (ដើម្បីកុំឱ្យរៀបរាប់ស្ទួន)៖**

| ផ្នែក | ព្រំដែន |
|---|---|
| ផ្នែក ២ | ឯកសារគោល (រឿងព្រេងដើម – ព្រះសត្ថា) |
| ផ្នែក ៦ | ពីការចាប់ផ្តើមអាណាព្យាបាលបារាំង (១៨៦៣) ដល់ការដួលរលំសង្គមរាស្ត្រនិយម (១៩៧០) |
| ផ្នែក ៧ | ១៩៧០–១៩៩៨ (សាធារណរដ្ឋខ្មែរ កម្ពុជាប្រជាធិបតេយ្យ សាធារណរដ្ឋប្រជាមានិតកម្ពុជា/រដ្ឋកម្ពុជា អ៊ុនតាក់ ដល់ការបញ្ចប់ចលនាខ្មែរក្រហម) |
| ផ្នែក ៨ | ១៩៩៨ ដល់កាលបរិច្ឆេទបិទទិន្នន័យ (ស្នើ៖ ៣០ មិថុនា ២០២៦) |

**ចន្លោះដែលទទួលស្គាល់៖** ឯកសារគោលបញ្ចប់នៅចុងសតវត្សទី១៦។ សម័យលង្វែកធ្លាក់ ឧដុង និងសតវត្សទី១៧–១៩ មុនអាណាព្យាបាល មិនត្រូវបានគ្របដណ្តប់ដោយឯកសារគោល ឬដោយផ្នែកណាមួយខាងលើទេ។ សម័យនេះនឹងត្រូវបានប្រើតែជា «ខ្សែបញ្ជូន» ក្នុងផ្នែក ៣ និង ៦ (ឧ. U091, U093, U092, U095) ដោយមិនរៀបរាប់ព្រឹត្តិការណ៍លម្អិត។

**ស្តង់ដារភស្តុតាង (ផ្នែក ៦.៣ របស់ Prompt)៖** ការអះអាងនីមួយៗថា «លក្ខណៈ X ពីអតីតកាលមានឥទ្ធិពលលើ Y សព្វថ្ងៃ» ត្រូវឆ្លងកាត់ការពិនិត្យ ៦ ជំហាន៖

1. លក្ខណៈដើម
2. មធ្យោបាយបញ្ជូន
3. ភស្តុតាងនៃការទទួលយក
4. ការប្រែប្រួល
5. ការបកស្រាយជំនួស
6. កម្រិតភាពប្រាកដប្រជា

បើគ្មានខ្សែបញ្ជូន ត្រូវហៅថា «ភាពស្រដៀងគ្នា» ឬ «សម្មតិកម្ម»។

### ៥.២ តារាងផ្នែកទាំង ១០

| ផ្នែក | ខ្លឹមសារ | ពាក្យ |
|---|---|---:|
| ១ | និយមន័យ ក្របខណ្ឌវិភាគ និងវិធីសាស្ត្រតាមដានឥទ្ធិពលប្រវត្តិសាស្ត្រ | ៤,០០០ |
| ២ | គំនិតអំពីអំណាច គុណធម៌ និងភាពស្របច្បាប់ក្នុងឯកសារគោល | ៥,០០០ |
| ៣ | យន្តការបញ្ជូន៖ គ្រួសារ សាសនា ការអប់រំ អក្សរសិល្ប៍ ពិធីការ និងស្ថាប័ន | ៥,០០០ |
| ៤ | ឋានានុក្រម បុគ្គលនិយមក្នុងអំណាច បណ្តាញឧបត្ថម្ភ ភាពស្មោះត្រង់ និងការតែងតាំងមនុស្ស | ៦,០០០ |
| ៥ | មរតកដែលអាចគាំទ្រការដឹកនាំល្អ៖ កាតព្វកិច្ចចំពោះប្រជាជន ការពិគ្រោះយោបល់ យុត្តិធម៌ និងការទទួលខុសត្រូវ | ៤,០០០ |
| ៦ | ការបន្ត និងការផ្តាច់ក្នុងសម័យអាណានិគម និងក្រោយឯករាជ្យ | ៦,០០០ |
| ៧ | សង្គ្រាម ការផ្លាស់ប្តូររបប ការបាក់បែកសង្គម និងការកសាងស្ថាប័នឡើងវិញ | ៦,០០០ |
| ៨ | មរតកវប្បធម៌ក្នុងការដឹកនាំសម័យបច្ចុប្បន្ន៖ ករណីសិក្សា និងភស្តុតាង | ៧,០០០ |
| ៩ | ការប្រៀបធៀបតាមសម័យ និងជាមួយប្រទេសក្នុងតំបន់ ដើម្បីសាកល្បងការបកស្រាយ | ៤,០០០ |
| ១០ | សំយោគលទ្ធផល មេរៀន និងដែនកំណត់ | ៣,០០០ |
| **សរុប** | | **៥០,០០០** |

### ៥.៣ មាតិកាលម្អិតតាមផ្នែក

---

#### ផ្នែក ១ — និយមន័យ ក្របខណ្ឌវិភាគ និងវិធីសាស្ត្រ (៤,០០០)

**សំណួរ៖** តើយើងអាចបញ្ជាក់ «ឥទ្ធិពលពីអតីតកាល» ដោយរបៀបណា ដើម្បីកុំឱ្យច្រឡំជាមួយភាពស្រដៀងគ្នា?

**ចំណុចរង៖**

| ចំណុច | ពាក្យ |
|---|---:|
| ៩.១.១ និយមន័យ «វប្បធម៌នៃការដឹកនាំ» និងគំនិតជិតខាង | ១,០០០ |
| ៩.១.២ ទ្រឹស្តី៖ ការចងចាំរួម ការបង្កើតប្រពៃណី ស្ថាប័ននិយមប្រវត្តិសាស្ត្រ និង path dependence | ១,២០០ |
| ៩.១.៣ ស្តង់ដារបញ្ជាក់ ៦ ជំហាន និងកម្រិតភាពប្រាកដប្រជា | ១,០០០ |
| ៩.១.៤ គ្រោះថ្នាក់នៃការពន្យល់ដោយ «វប្បធម៌» (cultural essentialism) | ៨០០ |

**យន្តការត្រូវសាកល្បង៖** មិនមាន — ផ្នែកនេះកំណត់ឧបករណ៍។

**ប្រភពត្រូវស្វែងរក៖** A017, A018, A019, A013, U105។

---

#### ផ្នែក ២ — គំនិតអំពីអំណាច គុណធម៌ និងភាពស្របច្បាប់ក្នុងឯកសារគោល (៥,០០០)

**សំណួរ៖** តើឯកសារគោលបង្ហាញគំនិតអ្វីខ្លះអំពីស្ដេចល្អ ភាពស្របច្បាប់ និងការស្តាប់បង្គាប់ ដែលអាចតាមដានទៅសម័យក្រោយ?

**ចំណុចរង៖**

| ចំណុច | ពាក្យ |
|---|---:|
| ៩.២.១ បុណ្យ បារមី និងធម៌ ក្នុងការរៀបរាប់ (សង្ខេបពីជំពូក ៤ — មិនស្ទួន) | ១,២០០ |
| ៩.២.២ វង្ស និងការផ្លាស់វង្ស៖ ត្រសក់ផ្អែម និងស្ដេចកន | ១,២០០ |
| ៩.២.៣ ព្រះពុទ្ធសាសនា និងរាជ្យ៖ ការសាងវត្ត ព្រះសង្ឃក្នុងពិធីស្នងរាជ្យ | ១,០០០ |
| ៩.២.៤ អ្នកតា ទំនាយ និងទឹកដី៖ ឃ្លាំងមឿង ដំបូកទាំងបួន | ៨០០ |
| ៩.២.៥ ការប្រៀបធៀបជាមួយអក្សរសិល្ប៍ច្បាប់ និងរាជធម៌ (ស្រទាប់ emic) | ៨០០ |

**យន្តការត្រូវសាកល្បង៖** គំនិតទាំងនេះជា «លក្ខណៈដើម» (ជំហាន ១) — ត្រូវកំណត់ថាវាមានក្នុងប្រភពណា មុនពេលអះអាងថាបន្តទៅសម័យក្រោយ។

**ប្រភពត្រូវស្វែងរក៖** ឯកសារគោល S01–S41, U074, U088, U089, A008–A011, A015។

**ចន្លោះភស្តុតាង៖** មិនទាន់ដឹងថាអក្សរសិល្ប៍ច្បាប់ណាខ្លះមានមុន ឬក្រោយពង្សាវតារ (ត្រូវផ្ទៀងផ្ទាត់កាលបរិច្ឆេទ)។

#### ផ្នែក ៣ — យន្តការបញ្ជូន (៥,០០០)

**សំណួរ៖** តើគំនិតអំពីការដឹកនាំត្រូវបានបញ្ជូនពីជំនាន់មួយទៅជំនាន់មួយតាមផ្លូវណា?

**ចំណុចរង៖**

| ចំណុច | ពាក្យ |
|---|---:|
| ៩.៣.១ ពង្សាវតារ និងការចម្លង៖ ការសរសេរឡើងវិញរបស់រាជវាំង និងវត្ត | ៩០០ |
| ៩.៣.២ ការអប់រំ៖ វត្ត សាលាអាណានិគម សៀវភៅសិក្សាប្រវត្តិសាស្ត្រសម័យឯករាជ្យ | ១,១០០ |
| ៩.៣.៣ អក្សរសិល្ប៍ និងសិល្បៈទស្សនីយភាព៖ រឿងព្រេង ល្ខោន ភាពយន្ត | ៩០០ |
