# ៩. បញ្ជីអ្នកដឹកនាំ និងករណីសិក្សាដែលស្នើ

## ៩.១ លក្ខណៈវិនិច្ឆ័យជ្រើសរើសករណីសិក្សា

គោលដៅ៖ **១២–២០ ករណីស៊ីជម្រៅ** និង **៣០–៤០ ករណីខ្លី**។ ក្នុងដំណាក់កាលនេះ ស្នើ ១៤ ករណីស៊ីជម្រៅ (C01–C14) និងបញ្ជីករណីខ្លីបឋម។ ករណីទាំងអស់ ⟨រង់ចាំភស្តុតាង⟩។

| លក្ខណៈវិនិច្ឆ័យ | របៀបអនុវត្តលើឯកសារគោល |
|---|---|
| **តំណាងសម័យកាល** | ឯកសារមិនមានសម័យហ្វូណន ចេនឡា អង្គរ ឬសម័យទំនើបទេ។ ដូច្នេះ «សម័យ» ត្រូវបានកំណត់តាមឯកសារ៖ <br>(១) រឿងព្រេងដើមរាជវង្ស <br>(២) ចុងអង្គរ សតវត្សទី១៤ <br>(៣) ចតុមុខ–ស្រីសន្ធរ សតវត្សទី១៥ <br>(៤) សង្គ្រាមរាជវង្ស និងលង្វែក សតវត្សទី១៦ <br>C01–C14 មានយ៉ាងហោចណាស់ ២ ករណីក្នុងសម័យនីមួយៗ |
| **ភាពខុសគ្នានៃលទ្ធផល** | ជោគជ័យ (C03, C10, C14) បរាជ័យ (C02, C06, C08) និងចម្រុះ (C04, C09, C13) |
| **គុណភាពភស្តុតាង** | ករណីសតវត្សទី១៦ (C08–C14) ទំនងជាមានប្រភពប្រៀបធៀបច្រើនជាង (ពង្សាវតារច្រើនកំណែ ពង្សាវតារអយុធ្យា ប្រភពអឺរ៉ុបនៅចុងសតវត្ស)។ ករណីរឿងព្រេង (C01, C05) ត្រូវបានប្រើសម្រាប់ការសិក្សាការចងចាំ និងភាពស្របច្បាប់ មិនមែនជាភស្តុតាងនៃព្រឹត្តិការណ៍ |
| **ភាពចម្រុះនៃតួអង្គ** | មិនមែនតែព្រះមហាក្សត្រប្រុសទេ៖ ដូនពេញ (C05) ពញាមឿង (C11) ព្រះឥសីភ័ទ្ទ (L039) ព្រះស្នំ (L034–L036) មន្ត្រី (L040–L043) ព្រះសង្ឃ (L044) |
| **ភាពប្រៀបធៀបបាន** | គូប្រៀបធៀបក្នុងជំពូក ៧៖ C02/C03, C04/C12, C09/C10, C10/C13 (ព្រះរាជវង្សពីរអង្គដែលពឹងលើអយុធ្យា) |

**ករណីដែលត្រូវដកចេញ ឬបន្ថយ** ប្រសិនបើការអានពេញបង្ហាញថា៖

- ឯកសារមានព័ត៌មានតិចពេកសម្រាប់គំរូវិភាគ ១០ ជំហាន
- ករណីនោះមានតែការរៀបរាប់សង្គ្រាម ដោយគ្មានសេចក្តីសម្រេចដែលអាចវិភាគបាន
- ប្រភពប្រៀបធៀបបង្ហាញថាការរៀបរាប់ទាំងមូលជាការខ្ចីរឿង
