# ៨. ការវិភាគឯកសារគោលខ្លួនវាផ្ទាល់

ផ្នែកនេះអនុវត្តផ្នែក ១៥ របស់ Prompt។ វាជាការវិភាគបឋម ផ្អែកលើការអានដែលបានរៀបរាប់ក្នុងផ្នែក ១.៣ ហើយនឹងត្រូវពង្រីកក្រោយការអានពេញ (ដំណាក់កាល ២ក)។

## ៨.១ អត្តសញ្ញាណឯកសារ

| សំណួរ | អ្វីដែលដឹង | ស្ថានភាព |
|---|---|---|
| ចំណងជើង | គ្មានចំណងជើងសៀវភៅ។ ផ្នែកនីមួយៗមានចំណងជើង «ផែនដី + ព្រះនាម» | ដឹងតែចំណងជើងផ្នែក |
| អ្នករៀបរៀង | មិនមានឈ្មោះក្នុងឯកសារ | **មិនទាន់ផ្ទៀងផ្ទាត់** |
| ការផ្សព្វផ្សាយ | ចម្លងពីគេហទំព័រមណ្ឌលវប្បធម៌ខ្មែរនៅស្វីស (ថត History/Ekasa) | ដឹងពីតំណក្នុងឯកសារ |
| ទំនាក់ទំនងជាមួយ «ឯកសារមហាបុរសខ្មែរ» របស់អេង សុត | អាចទៅរួច ប៉ុន្តែគ្មានភស្តុតាងក្នុងឯកសារ ហើយការស្វែងរកមួយលើកមិនបានបញ្ជាក់ | **មិនទាន់ផ្ទៀងផ្ទាត់** |
| ភាគ កំណែ ឆ្នាំ អ្នកបោះពុម្ព | មិនមាន | **មិនទាន់ផ្ទៀងផ្ទាត់** |

**សញ្ញាពីអត្ថបទ (មិនមែនភស្តុតាងនៃអត្តសញ្ញាណ)៖** អត្ថបទមាន «សំឡេងអ្នករៀបរៀង» ច្បាស់លាស់៖

- **ការពន្យល់ពាក្យក្នុងវង់ក្រចក៖** ឧ. «តប្រយូរវង្ស (ប្រែថា ផៅពង្ស…)», «ព្រះមែយ្យ (ពាក្យសៀម…)», «ខ្លោងមឿង គឺអ្នកតាចាំស្រុក…»។
- **ការប្រៀបធៀបកំណែពង្សាវតារ៖** ឧ. ព្រះរាជពង្សាវតារភាគ២ នៃព្រះរាជបណ្ណាល័យ «លេខ គ ៥៣» ទំព័រ ៦៤ ៦៨ ៦៩ ដែលដាក់ការឡើងរាជ្យរបស់ព្រះបាទត្រសក់ផ្អែមនៅ គ.ស. ១២៩០ ខុសពីតួអត្ថបទ (គ.ស. ៩៩៨)។
- **ការនិយាយទៅកាន់អ្នកអាន៖** ឧ. «លោកអ្នកអានប្រហែលជានៅចាំបានថា…»។
- **ការភ្ជាប់ទីកន្លែងបុរាណទៅទីកន្លែងបច្ចុប្បន្ន៖** ឧ. «សព្វថ្ងៃនៅក្នុងខែត្រកំពង់ស្ពឺ ក្បែរផ្សារឧដុង្គ»។

លក្ខណៈទាំងនេះបង្ហាញថាឯកសារជា **ការរៀបរៀងដោយមានការកែសម្រួល** មិនមែនការចម្លងពង្សាវតារមួយកំណែដោយផ្ទាល់ទេ។ ប៉ុន្តែយើងមិនទាន់អាចបែងចែកថាសំឡេងណាជារបស់អ្នករៀបរៀងដើម ហើយសំឡេងណាជារបស់អ្នកចម្លងទៅគេហទំព័រ។

## ៨.២ លក្ខណៈឯកសារ

**ការកំណត់៖ ឯកសារចម្រុះ — ពង្សាវតាររៀបរៀងឡើងវិញ ដែលមានរឿងព្រេង និងការពន្យល់របស់អ្នករៀបរៀង។**

**មូលដ្ឋាន៖**

1. **រចនាសម្ព័ន្ធពង្សាវតារ៖**
   - តាមរជ្ជកាល («ផែនដី»)
   - កាលបរិច្ឆេទជាច្រើនប្រព័ន្ធ (ព.ស. គ.ស. ម.ស. ច.ស. ឆ្នាំសត្វ និងស័ក)
   - ភាសារាជស័ព្ទ
   - ការរៀបរាប់ពិធីរាជ្យ និងសង្គ្រាម
2. **ធាតុរឿងព្រេង៖**
   - រឿងត្រសក់ផ្អែម (ព្រះជន្ម «៤៥០ ឆ្នាំ»)
   - ព្រះអង្គរតនមាលី និងក្រពើ
   - ទំនាយ «ដំបូកទាំងបួន»
   - អ្នកតាឃ្លាំងមឿង
3. **ធាតុការសិក្សា៖**
   - ការប្រៀបធៀបកំណែ
   - ការពន្យល់ពាក្យ
   - ការកត់សម្គាល់ភាពមិនស៊ីគ្នា («បើថា ៤៥៣ឆ្នាំ ទើបត្រូវនឹងរឿងខាងក្រោម»)

**ផលវិបាកចំពោះការប្រើប្រាស់៖** ការអះអាងពីឯកសារត្រូវបានបែងចែកជាបីស្រទាប់៖

| ស្រទាប់ | ខ្លឹមសារ |
|---|---|
| ក | អ្វីដែលពង្សាវតាររៀបរាប់ |
| ខ | អ្វីដែលអ្នករៀបរៀងពន្យល់ ឬវិនិច្ឆ័យ |
| គ | អ្វីដែលអ្នកស្រាវជ្រាវ (សៀវភៅនេះ) បកស្រាយ |

## ៨.៣ ប្រភពដែលអ្នករៀបរៀងប្រើ (តាមដែលឯកសារបង្ហាញ)

| ប្រភព | ភស្តុតាងក្នុងឯកសារ | ការប្រើក្នុងគម្រោង |
|---|---|---|
| ព្រះរាជពង្សាវតារភាគ២ ព្រះរាជបណ្ណាល័យ លេខ គ ៥៣ | ដកស្រង់ទំព័រ ៦៤ ៦៨ ៦៩ ក្នុង S01 | ត្រូវរកថាជាកំណែណា ក្នុងការសិក្សារបស់ Mak Phoeun/Khin Sok (A001, U094) |
| ព្រះរាជពង្សាវតារភាគ៣ «គ. ៥៣-៣» | ចំណងជើងតូចក្នុង S33 និងការដកស្រង់ក្នុង S41 | ដូចខាងលើ |
| «ព្រះរាជពង្សាវតាររបស់ព្រះរាជបណ្ណាល័យ» (កំណែខ្លី) | អ្នករៀបរៀងប្រាប់ថា «មាននិយាយត្រង់នេះដែរ តែខ្លីណាស់» (S32) | បង្ហាញថាមានកំណែវែង និងខ្លី |
| សាស្ត្រាវត្តកំពង់ត្រឡាចក្រោម | ដកស្រង់ក្នុងលេខយោងនៃ S25 (ឈ្មោះ «ពេជ» សម្រាប់តាមឿង) | ពង្សាវតារវត្ត — ត្រូវរកក្នុងការសិក្សា |
| «សាស្ត្រាខ្លះថា…» | ចំណងជើង S19–S20 និងលេខយោង | កំណែផ្សេងៗដែលមិនបញ្ជាក់ឈ្មោះ |
| រឿងព្រេង និងប្រពៃណីផ្ទាល់មាត់ | រឿងត្រសក់ផ្អែម ដូនពេញ ឃ្លាំងមឿង | ប្រើសម្រាប់ការសិក្សាការចងចាំ (កម្រិត ឃ) |
| សិលាចារឹក ការសិក្សាបារាំង | **មិនទាន់ឃើញ** ក្នុងផ្នែកដែលបានអាន | ត្រូវពិនិត្យក្នុងការអានពេញ |

## ៨.៤ លក្ខណៈវិនិច្ឆ័យនៃ «មហាបុរស» ក្នុងឯកសារ (បឋម)

ការរាប់ពាក្យខាងក្រោមធ្វើលើឯកសារទាំងមូល។ វាបង្ហាញពីអ្វីដែលអត្ថបទយកចិត្តទុកដាក់ មិនមែនពីអត្ថន័យនៃការប្រើនីមួយៗទេ (ត្រូវអានបរិបទ)។

| សញ្ញា | ចំនួនដង | ការបកស្រាយបឋម |
|---|---:|---|
| «សៀម» / «អយុធ្យា» | ៥២០ / ៨៦ | សង្គ្រាម និងទំនាក់ទំនងជាមួយអយុធ្យា ជាប្រធានបទកណ្តាល |
| «លាវ» | ២០៧ | ទំនាក់ទំនងជាមួយលានជាង (ត្រូវអានបរិបទ) |
| «បុណ្យ» / «បារមី» | ១៣០ / ៤៥ | ភាពស្របច្បាប់ផ្អែកលើបុណ្យ និងបារមី |
| «ទំនាយ» / «ព្យាករណ៍» / «អ្នកតា» | ៤៣ / ៧ / ២២ | ពិភពជំនឿជាផ្នែកនៃការសម្រេចចិត្ត |
| «ព្រះស្ដេចកន» / «ស្ដេចកន» | ១៧៨ / ៩៤ | តួអង្គដែលឯកសារយកចិត្តទុកដាក់ច្រើនជាងគេ |
| «ចៅពញាចន្ទរាជា» | ១១០ | តួអង្គកណ្តាលទីពីរ |
| «ព្រះសង្ឃ» / «សង្ឃរាជ» | ៤៥ / ៨ | ព្រះសង្ឃក្នុងពិធី និងការសម្រុះសម្រួល |

**សម្មតិកម្មត្រូវសាកល្បង៖** ឯកសារវាយតម្លៃអ្នកដឹកនាំតាមលក្ខណៈវិនិច្ឆ័យប្រាំ៖

1. ភាពស្របច្បាប់នៃវង្ស
2. ជ័យជម្នះលើសត្រូវខាងក្រៅ (ជាពិសេសអយុធ្យា)
3. បុណ្យ បារមី និងការគាំទ្រពុទ្ធសាសនា (ការសាងវត្ត)
4. ការកសាងរាជធានី
5. ការគោរពទំនាយ និងទំនៀមរាជ្យ

សុខុមាលភាពប្រជាជនកម្របង្ហាញជាលក្ខណៈវិនិច្ឆ័យដាច់ដោយឡែក។

**ភាសាវាយតម្លៃ៖** ឯកសារប្រើរាជស័ព្ទពេញលេញចំពោះស្ដេចដែលខ្លួនចាត់ទុកថាស្របច្បាប់ ប៉ុន្តែប្រើពាក្យ «អា» ចំពោះស្ដេចកន (ឧ. «អា "កន"» ក្នុងព្រះរាជសាររបស់ព្រះចន្ទរាជា S33) ទោះបីឯកសារខ្លួនឯងរៀបរាប់ថាស្ដេចកនបានឡើងគ្រងរាជ្យដោយមានព្រះនាមរាជាភិសេក «ព្រះបាទសម្ដេចព្រះស្រីជេដ្ឋាធិរាជរាមាធិបតី» (S25–S27)។ ភាពមិនស៊ីគ្នានេះ គឺជាភស្តុតាងសំខាន់សម្រាប់ C09 និងសម្រាប់ការសិក្សា «ភាពលម្អៀងរបស់អ្នកឈ្នះ»។

## ៨.៦ ភាពខុសគ្នាដែលរំពឹងទុកជាមួយការសិក្សាវិជ្ជាការ (ត្រូវផ្ទៀងផ្ទាត់)

1. **កាលប្បវត្តិ៖**
   - កាលបរិច្ឆេទសម្រាប់សតវត្សទី១៤–១៥ ក្នុងឯកសារ ត្រូវប្រៀបធៀបជាមួយ A002 និង A001។
   - ឯកសារខ្លួនឯងមានកាលបរិច្ឆេទពីរខុសគ្នា ៣០០ ឆ្នាំ សម្រាប់ព្រះបាទត្រសក់ផ្អែម។
2. **ភាពជឿជាក់នៃផ្នែកសតវត្សទី១៤៖** ការរៀបរាប់ពីការកាន់កាប់ដោយព្រះរាជវង្សអយុធ្យា (S09–S16) ត្រូវប្រៀបធៀបជាមួយប្រភពអយុធ្យា ដើម្បីដឹងថាវាជាប្រភពឯករាជ្យ ឬជាការខ្ចីរឿងពីគ្នា (ផ្នែក ៤.៥ របស់ Prompt៖ កុំរាប់ប្រភពច្រើនដែលពឹងលើប្រភពតែមួយ ជាភស្តុតាងឯករាជ្យ)។
3. **តួលេខ៖** តួលេខកងទ័ព និងអាយុ («ព្រះជន្ម ៤៥០ ឆ្នាំ», «១២០ ឆ្នាំ») ជាធាតុរឿងព្រេង ឬការបំផ្លើស។
4. **ការវាយតម្លៃស្ដេចកន៖** ការសិក្សា និងការបកស្រាយសម័យថ្មីខ្លះ ទំនងជាមើលស្ដេចកនខុសពីឯកសារ (ត្រូវផ្ទៀងផ្ទាត់ជាមួយ A012, U259)។

## ៨.៧ គោលការណ៍ប្រើប្រាស់ក្នុងសៀវភៅ

- ពេលសង្ខេបការរៀបរាប់៖ «យោងតាមឯកសារគោល…», «ពង្សាវតារដែលអ្នករៀបរៀងដកស្រង់ពណ៌នាថា…»។
- ពេលដកស្រង់ការពន្យល់របស់អ្នករៀបរៀង៖ «អ្នករៀបរៀងពន្យល់ថា…»។
- ពេលបកស្រាយ៖ «សៀវភៅនេះបកស្រាយថា…» ឬ «ការបកស្រាយមួយដែលអាចទៅរួចគឺ…»។
- ហៅឯកសារថា «ឯកសារមហាបុរសខ្មែរ» តែក្រោយពេលបញ្ជាក់អត្តសញ្ញាណ។ មុននោះ ហៅថា «ឯកសារគោល»។
- យោងទីតាំងជា «ឯកសារគោល S##» រហូតដល់មានលេខទំព័របោះពុម្ព។ ក្រោយមក ប្រើតារាងប្តូរលេខ S → ទំព័រ។
