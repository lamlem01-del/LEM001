# ១២. វិធីរាប់ពាក្យ ការប៉ាន់ស្មានទំព័រ និងទម្រង់ជំពូកគំរូ

## ១២.១ វិធីរាប់ពាក្យខ្មែរ

**ឧបករណ៍ដែលបានប្រើ៖**

- **khmer-nltk** — ម៉ូដែល CRF សម្រាប់បំបែកពាក្យខ្មែរ។ ICU BreakIterator មិនអាចដំឡើងក្នុងបរិស្ថានការងារនេះបានទេ។
- កម្មវិធី `tools/count_source_words.py` (មាននៅក្នុងឃ្លាំងឯកសារ ដើម្បីឱ្យអាចធ្វើឡើងវិញបាន)។

**ក្បួនរាប់៖**

1. ដករូបភាព តំណ និងសម្ភារៈម៉ឺនុយវេប។
2. ដកដកឃ្លា និង zero-width space ចេញ មុនការបំបែក ដើម្បីកុំឱ្យលទ្ធផលពឹងលើរបៀបវាយអក្សររបស់អ្នកវាយ។
3. បំបែកពាក្យ ហើយរាប់តែ token ដែលមានអក្សរខ្មែរយ៉ាងហោចណាស់មួយ — មិនរាប់វណ្ណយុត្តិ លេខ ឬអក្សរឡាតាំង។
4. រាយការណ៍ទាំង **ពាក្យ** និង **តួអក្សរខ្មែរ** (U+1780–U+17DD) សម្រាប់ផ្នែកនីមួយៗ។

**លទ្ធផលលើឯកសារគោល៖**

| រង្វាស់ | តម្លៃ |
|---|---:|
| ពាក្យ (khmer-nltk) | ១១១,៩៣៧ |
| តួអក្សរខ្មែរ | ៤៨៨,៤៥២ |
| តួអក្សរ ក្នុងមួយពាក្យ | ≈ ៤.៣៦ |
| ផ្នែកដែលបំបែកដោយ zero-width space ឬដកឃ្លា (មិនមែនពាក្យ — សម្រាប់ប្រៀបធៀបតែប៉ុណ្ណោះ) | ១៣៧,៨២២ |

ភាពខុសគ្នារវាងការរាប់តាម zero-width space (១៣៧,៨២២) និងការបំបែកពាក្យ (១១១,៩៣៧) គឺប្រមាណ ២៣%។ នេះបង្ហាញថាការរាប់ចន្លោះ **មិនអាចប្រើជាចំនួនពាក្យបានទេ** (ផ្នែក ៧ របស់ Prompt)។

**ការក្រិតតាមខ្នាត — មិនទាន់ធ្វើ៖** ការរាប់ដោយដៃលើអត្ថបទគំរូ ៥០០–១,០០០ ពាក្យ មិនទាន់បានធ្វើទេ។ ផែនការ៖

1. ជ្រើសគំរូ ៣ (ពង្សាវតារ ១, អត្ថបទវិភាគរបស់សៀវភៅ ១, តារាង/លេខយោង ១) ប្រមាណ ៣០០ ពាក្យនីមួយៗ។
2. អ្នក (ឬអ្នកជំនាញភាសាខ្មែរ) បំបែកពាក្យដោយដៃ តាមវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ជាគោល។ ពាក្យសមាសដែលមានក្នុងវចនានុក្រមជាធាតុតែមួយ រាប់ ១។
3. ប្រៀបធៀបជាមួយលទ្ធផលឧបករណ៍ ហើយគណនាអត្រាខុស និងមេគុណកែតម្រូវ។
4. ប្រើឧបករណ៍ និងមេគុណដដែលគ្រប់ផ្នែកនៃសៀវភៅ។

រហូតដល់ពេលនោះ ចំនួនពាក្យទាំងអស់ត្រូវបានសម្គាល់ថា **«ការវាស់ដោយឧបករណ៍ មិនទាន់ក្រិតតាមខ្នាត»**។

## ១២.៣ ទម្រង់ជំពូកគំរូ (ផ្នែក ២២ របស់ Prompt)

```text
ជំពូក [លេខ] — [ចំណងជើង]

[សេចក្តីសង្ខេបជំពូក ១៥០–២៥០ ពាក្យ]
សំណួរដែលជំពូកនេះឆ្លើយ៖ ១. … ២. … ៣. …

[លេខ].១ បរិបទ និងកាលប្បវត្តិខ្លី
    — តារាងកាលប្បវត្តិតូច (កាលបរិច្ឆេទតាមឯកសារ + កាលបរិច្ឆេទតាមការសិក្សា)

[លេខ].២ … [លេខ].៦ តួអត្ថបទវិភាគ
    — ករណីនីមួយៗ៖ បរិបទ → បញ្ហាប្រឈម → ជម្រើសដែលមាន → សេចក្តីសម្រេច →
      ភស្តុតាងអំពីចរិតដឹកនាំ → ផលភ្លាមៗ → ផលរយៈពេលវែង →
      ការវាយតម្លៃតាមលក្ខណៈវិនិច្ឆ័យ វ១–វ៥ → ការបកស្រាយជំនួស → មេរៀន និងដែនកំណត់
    — ការអះអាងសំខាន់ៗមានកម្រិត [ក–ឃ] ក្នុងលេខយោង

តារាងសង្ខេបការវាយតម្លៃ (emic | etic | ស្រប/ខុស | មូលហេតុ)

សេចក្តីសន្និដ្ឋានជំពូក និងការភ្ជាប់ទៅជំពូកបន្ទាប់

កំណត់ត្រាការងារ (មិនបោះពុម្ព)៖ ប្រភពដែលប្រើ · ចំណុចត្រូវផ្ទៀងផ្ទាត់ ·
```
